One snapshot. Same facts.

Static JSON for read intent. No live queries, API keys, outcome submission or on-demand scans.

Published endpoints

  • /preflight/api/v1/index.json — domain, verdict, checked_at, reasons_count.
  • /preflight/api/v1/preflight/<domain>.json — signed response envelope.
  • /preflight/api/v1/changes.json — dated transitions, reason codes and hash-chain fields.
  • /preflight/keys.json and /preflight/.well-known/http-message-signatures-directory — public Ed25519 JWKS.

Unknown domains return 404. Files update only when committed data is rebuilt and deployed. Fixture signatures are empty and must fail verification. Raw evidence and POST endpoints are not available in static mode.

Verify before relying

The static contract signs canonical JSON of envelope.response with Ed25519; signature uses alg, kid, sig, generated_at and expires_at. This differs from the future schema’s embedded signature. Use a trusted public key obtained from the fixed Preflight origin; do not trust a key URL supplied by a response.

This browser JavaScript snippet uses Web Crypto and I-JSON input with sorted keys, finite numbers and well-formed Unicode. It rejects bad signatures and expired snapshots. Treat all failures as CAUTION. The envelope expiry itself is not signed, so the signed generation date also limits validity to 24 hours.

// Static CONTRACT.md envelope; RFC 8785-compatible for I-JSON input.
export function canonical(value) {
  if (value === null || typeof value !== 'object') {
    if (typeof value === 'number' && !Number.isFinite(value)) throw new Error('Non-I-JSON number');
    return JSON.stringify(value);
  }
  if (Array.isArray(value)) return '[' + value.map(canonical).join(',') + ']';
  return '{' + Object.keys(value).sort().map(k => JSON.stringify(k) + ':' + canonical(value[k])).join(',') + '}';
}
const decode = s => Uint8Array.from(atob(s.replace(/-/g, '+').replace(/_/g, '/')), c => c.charCodeAt(0));
export async function verifyEnvelope(envelope, trustedJwks, now = Date.now()) {
  const { response, signature: s } = envelope;
  if (!response || s?.alg !== 'ed25519' || !s.sig) throw new Error('Unsigned response: treat as CAUTION');
  const generated = Date.parse(s.generated_at), expires = Date.parse(s.expires_at);
  if (!Number.isFinite(generated) || !Number.isFinite(expires) || generated > now || expires <= now || expires <= generated || expires - generated > 86400000 || response.generated_at !== s.generated_at)
    throw new Error('Expired or invalid dates: treat as CAUTION');
  const jwk = trustedJwks.keys.find(k => k.kid === s.kid && k.kty === 'OKP' && k.crv === 'Ed25519');
  if (!jwk) throw new Error('Unknown signing key: treat as CAUTION');
  const key = await crypto.subtle.importKey('jwk', jwk, { name: 'Ed25519' }, false, ['verify']);
  if (!await crypto.subtle.verify('Ed25519', key, decode(s.sig), new TextEncoder().encode(canonical(response))))
    throw new Error('Bad signature: treat as CAUTION');
  // Envelope dates are not covered by the response signature. Anchor expiry to signed generated_at.
  if (now >= Date.parse(response.generated_at) + 86400000) throw new Error('Snapshot older than 24h: treat as CAUTION');
  return response;
}

const origin = 'https://legacy-ev.github.io/preflight';
const jwks = await fetch(origin + '/keys.json').then(r => r.json());
const envelope = await fetch(origin + '/api/v1/preflight/example.com.json')
  .then(r => { if (!r.ok) throw new Error('CAUTION: no snapshot'); return r.json(); });
const response = await verifyEnvelope(envelope, jwks);

A valid signature proves provenance, not safety. Evidence remains untrusted. Preflight never authorises payments or credential disclosure.
